# 🤝 Contributing to OmeBox

Thanks for wanting to improve **OmeBox**! 🎁

Suggestions, feedback, and ideas are always welcome.

---

## Ways to Contribute

- 🐛 **Report bugs** — [Open an issue](https://github.com/yourusername/omebox/issues)
- 💡 **Suggest features** — [Open an issue](https://github.com/yourusername/omebox/issues)
- 📖 **Improve docs** — Fix typos, clarify wording
- 🎨 **Suggest UI/UX improvements**
- 🔗 **Share OmeBox** with others

---

## Reporting a Bug

When opening an issue, please include:

1. **Description** — What went wrong?
2. **Steps to reproduce** — How can we see it?
3. **Expected behavior** — What should have happened?
4. **Screenshots** — If applicable
5. **Device & browser** — e.g., iPhone 13 / Chrome 120

---

## Suggesting a Feature

Include:

1. **Problem** — What problem does it solve?
2. **Solution** — Your proposed idea
3. **Alternatives** — Other approaches you considered
4. **Screenshots / mockups** — If available

---

## Important Note

OmeBox is a **proprietary project**. This repository is a **public showcase**.

- ✅ Suggestions and bug reports are welcome
- ❌ Code pull requests are not accepted (source is closed)
- ⚠️ Please do not redistribute the code

---

Thank you for your interest in OmeBox! 💜
